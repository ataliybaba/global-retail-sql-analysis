# 📊 Global Retail SQL Analysis

## 📌 Project Overview
This project is a business intelligence analysis of a global retail company. Using **PostgreSQL** and **Power BI**, I analyzed sales, revenue, and profitability across four global regions (North America, Europe, Greater China, and Asia Pacific).

## 🛠️ Tech Stack
- **Database:** PostgreSQL (pgAdmin 4)
- **Visualization:** Microsoft Power BI
- **Version Control:** GitHub Desktop

## 📈 Key Insights
- Calculated total revenue and profit margins to identify the most profitable regions.
- Identified the top-selling products by category and quantity.
- Built a Power BI dashboard to visualize regional performance and product distribution.

## 📂 Files in this Repository
- `Retail.analysis.sql.txt`: Contains the SQL queries used to clean, join, and analyze the data.
- `Global_Retail_Dashboard.pdf`: A PDF export of the Power BI dashboard built from this database.

## 🗄️ Database Structure
- **`regions`**: Stores regional names and managers.
- **`products`**: Stores product names, categories, and unit prices.
- **`sales`**: Tracks transactions, quantities, revenue, and costs.
